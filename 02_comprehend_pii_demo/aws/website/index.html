Spotting possible bias with Amazon Comprehend

            

                Comprehend has no bias-detection API. What it gives you are signals: sentiment and toxicity.
                This page uses them two ways: (1) compare sentiment across demographic groups for text that should be
                treated alike, and (2) flag hateful or abusive wording. A gap is a prompt to investigate, not proof of bias.
                For statistical bias audits of datasets and models, use Amazon SageMaker Clarify.
            


            

                
                
            


            
            

                

                    Run text about different groups through Comprehend's sentiment analysis and compare the averages. If
                    equivalent situations get systematically more negative wording for one group, that is a bias signal.
